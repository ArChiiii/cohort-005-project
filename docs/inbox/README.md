# Inbox

Deferred concerns, issues, and ideas captured during work for later review.
Each file is a self-contained markdown note with frontmatter (`captured`, `source`, `status`).

- **Open items** live at the top level.
- **Resolved items** are moved to `archive/`.
- Files are sorted chronologically by filename (`YYYY-MM-DD-<slug>.md`).

Add new items via `/inbox <description>` (Claude Code) or just drop a markdown file here.
